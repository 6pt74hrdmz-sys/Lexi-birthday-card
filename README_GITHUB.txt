GitHub Pages 运行说明

1. 在 GitHub 新建一个 Public repository，例如 birthday-particle-card。
2. 上传本文件夹里的全部内容：index.html、photos 文件夹和 .nojekyll。
3. 打开 Settings → Pages。
4. Build and deployment → Source 选择 Deploy from a branch。
5. Branch 选择 main，目录选择 / (root)，点击 Save。
6. 等待部署完成后，用 GitHub Pages 给出的 https://用户名.github.io/仓库名/ 打开。
7. 点击“启用摄像头 & 开始体验”，允许浏览器使用摄像头。

不需要安装 Python、Node.js 或其他本地环境。
